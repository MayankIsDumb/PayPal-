# Demo assets

Reproducible JAR payloads for the 3-minute demo and judge walkthrough.

```bash
./gradlew generateDemoAssets
```

| File | Contents | Expected result |
|---|---|---|
| `broken-submission.jar` | Valid ZIP/JAR with a manifest and `README.txt`; no compiled classes, no `fabric.mod.json` | **Blocked** — funds stay held, failed checks appear in the evidence drawer |
| `verified-motionblur-1.21.jar` | Valid JAR with `fabric.mod.json` (`id: afkzmotionblur`, `version: 1.2.0`), two `CAFEBABE` class headers, manifest, and a language file | **Verified → captured** — creator is paid automatically |

The class entries in the verified fixture are header-valid skeletons, not loadable mod code. The verifier never executes uploads; it only inspects archive structure, bytecode magic, and metadata.

Both files are generated by the `generateDemoAssets` Gradle task and use fixed ZIP timestamps so the archives are reproducible.
